# Auto Mode & Non-Interactive Execution Rule

## Direct Execution Guidelines
1. **No Unnecessary Interactive Modals**: Do not call `ask_question` or pause for interactive UI feedback unless critical ambiguity prevents proceeding safely. Make sensible defaults and proceed directly with code implementation, testing, and deployment.
2. **Autonomous Task Completion**: Perform all necessary file views, edits, script runs, and verification steps continuously without asking the user for step-by-step confirmation.
3. **Clear Summaries**: Provide clear, concise final summaries after completing work.
